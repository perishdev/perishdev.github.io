# perish.dev

Embracing decay, evolving ideas.

We build software with a clear understanding that nothing lasts forever — and treat that as a feature, not a flaw. Code, services, infrastructure, even ideas: they're meant to be revisited, reshaped, retired. The goal isn't permanence; it's making the transitions deliberate.

## What lives here

- [`perishdev`](https://github.com/perishdev) on GitHub — our public work.
- [`perishdev/infra`](https://github.com/perishdev/infra) — the infrastructure that runs `perish.dev` itself, fully public and Terraform-managed.
